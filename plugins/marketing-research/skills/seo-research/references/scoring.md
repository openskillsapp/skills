# Scoring queries

Score each query 1 to 3 on four factors, then sort by the total. Show the
scores in the table so the user can disagree with one factor without
redoing the list.

| Factor | 3 | 2 | 1 |
| --- | --- | --- | --- |
| **Fit** | Searcher wants what the user sells | Related; the user can help and mention the product | Topic only; little path to a sale |
| **Format match** | The winning page type is one the user can build well | Mixed page types; one the user can build is present | Winning type is one the user can't credibly build (e.g. a marketplace, a giant retailer's category page) |
| **Beatability** | A weak page in the top 5: a forum thread, an old or thin page, or a domain well below the user's authority | Top results within about 15 rating points of the user | Top 5 all far stronger domains with pages made for the query |
| **Demand** | Known volume or a rising Trends line; many related queries | Steady or unknown but plausible | Falling Trends line or almost no related queries |

Notes:

- **Beatability uses the user's own authority** as the yardstick, measured
  with the same call.
- **SERP features lower the value of position 1.** If an answer box or AI
  Overview answers the query outright, mark it, and prefer queries where a
  click is still needed (comparisons, tools, buying decisions).
- **A forum or video result in the top 3** usually means searchers want
  first-hand experience; a page needs real examples to compete.
- **The user already ranking 4 to 15** is the quickest win: improve that
  page rather than writing a new one.
